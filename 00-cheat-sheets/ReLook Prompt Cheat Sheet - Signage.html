Logo & Element Swaps (Actual Prompts Used)
Logo Swap — 2 Images
"Change the logo in the first pic with the logo in the 2nd pic"
Image 1 = signage scene. Image 2 = new logo. AI composites with correct perspective.
Element Swap — 2 Images
"Remove the surfboard in first pic and swap with the mascot in the 2nd pic"
Remove + replace in one prompt. Works for mascots, props, display elements.
Sketch → 3D Render (Master Prompt)
Line Drawing → Branded Booth Render (Actual Prompt Used)
Image 1 = Booth line drawing (structure master)

"Photorealistic 3D render of a modern exhibition booth based on a conceptual sketch. Transform the sketch into a fully built structure with realistic geometry, clean edges, and accurate proportions."

Booth design: A [CLIENT] branded expo stand with [angular / curved / open] architecture, illuminated fascia, and a reception counter. Integrated lighting within edges and signage.

Materials: [Matte white laminated panels], [brushed aluminium framing], [soft LED strip lighting]

For a neutral base: "Generate the rendered version of these line drawings, neutral colour palette" — then apply branding as a second step.
Multi-Image Panel Graphics — Signage Superpower
Apply Graphics to Named Panels (Actual Prompt Used)
Image 1 = Booth with labelled panels (A, B, C) Images 2–4 = Graphic designs for each panel

"Add the graphics on panels A, B, C of the first pic using the image 1, 2 and 3"

The AI maps each graphic to its designated panel, auto-matching perspective, lighting, and scale. Label your panels clearly in the booth structure image. Up to 4 reference images supported.
Lighting, Background & Furniture Control
Lighting / Time Change
"Change lighting to midday"
Shifts entire scene — shadows, sky, reflections update. Works for night→day, indoor→outdoor feel.
Background Removal
"Remove the background — keep the scene intact"
Isolates signage with transparency. Ready for composite into any venue or proposal.
Furniture Swap — 2 Images
"Swap the chairs in 1st pic with the chair in 2nd pic"
Pull specific furniture from a reference photo into your booth. Instant variation.
Material / Finish Change
"Change the booth panels from [current] to [gloss white / brushed aluminium / timber veneer]"
Material changes shift perceived quality. Generate before showing client.
Power Tips
1
Generate neutral first. Create an unbranded booth render, then apply client branding as a second prompt. Easier to pivot when briefs change.
2
Label panels clearly. When using multi-image panel graphics, mark panels A, B, C on your booth image. The AI reads the labels.
3
Name materials precisely. "Matte white laminated panel" beats "white wall". "Brushed aluminium trim" beats "metal". Precision = accuracy.
4
Premium 2K always for client-facing signage renders. Fast model for quick internal layout checks only.
5
Iterate, don't restart. V1 = structure. V2 = branding. V3 = graphics. V4 = lighting. V5 = furniture. Each builds on the last.
6
Background removal for composites. Remove background from a signage render, then place it into a venue photo for proposals.
