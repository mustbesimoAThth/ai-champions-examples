Materials & Finishes
Metal Finish Swap
"Change all the metal finishing (background and base object) to [black metal matte / brushed gold / polished chrome]"
Actual prompt from VRC champagne tower revision
Surface Material
"Replace the [timber / concrete / render] surfaces with [marble / exposed brick / white plaster]"
Works on: walls, floors, countertops, facade panels
Glass & Transparency
"Change the windows to [tinted glass / frosted glass / clear glass with reflections]"
For pavilion facades, office partitions, display cases
Cladding Swap
"Change the exterior cladding from [dark panels] to [white aluminium composite / timber battens / corrugated metal]"
Used for the AFL September Club facade revision
Structural Changes (Sketch Inpaint Mode)
Height Adjustment
"Raise the height of the [curved wall / partition / bar counter] as per the pink sketch"
Draw a pink overlay on the image showing desired height — AI interprets it
Add Architectural Element
"Add a [canopy / awning / rooftop terrace] to the area marked in the sketch"
Sketch the rough shape + position, prompt describes what it should be
Remove Element
"Remove the [column / barrier / signage] in the marked area and fill with the surrounding material"
Paint over what you want removed, prompt tells AI what to replace with
Extend / Widen
"Extend the [balcony / bar top / facade panel] to the width shown in the sketch"
Draw the new boundary and the AI fills in consistently
Element Swapping (Multi-Reference Mode)
Furniture from Ref
"Change the stools of the 1st pic with the stool in the 2nd pic"
Actual prompt used — upload venue photo + product photo as references
Lighting Fixtures
"Replace the pendant lights with the [chandelier / track lighting / globe lights] shown in reference 2"
Upload the HTH product image or a mood reference
Stand Re-skinning
"Keep the same booth structure but rebrand for [client name] using the colours and logo from reference 2"
Exhibition teams: same shell, new client — instant pitch visual
Combine Best Elements
"Use the bar layout from image 1, the seating from image 2, and the lighting from image 3"
Up to 5 references. Each adds a different element to the final composite
Exhibition Stands (Custom Upgrades)
Booth Visualisation
"Show this exhibition stand with [LED backlit panels / living green wall / projector screen] on the rear wall"
Great for upselling upgrade options to exhibitors
Flooring Upgrade
"Change the booth flooring to [raised timber deck / branded carpet / polished concrete]"
Flooring dramatically changes the perceived quality of a stand
Power Tips
1
Sketch inpaint = structural. If you're changing shape, height, or position, draw it. If you're changing colour or material, just type it.
2
Be specific about what stays. "Change the metal finish to black matte but keep the glass and timber as is" prevents unwanted changes.
3
Use 9:16 Vertical for social media previews and client Instagram stories. Use standard for technical documentation and decks.
4
Premium 2K for client-facing. Fast model for quick internal explorations. Premium for anything going into a proposal.
5
Multi-ref = composition. Reference 1 is your base scene. References 2-5 are elements you want placed into it.
6
Material names matter. "Black metal matte" is better than "dark metal." "Brushed brass" is better than "gold." Be precise.
