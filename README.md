# AI Champions — Best Prompt & Image Examples

The showreel: the best of the AI Champions library, pulled out of `_Organized` and arranged so you
can teach from it. 24 real-world case studies across 10 departments, each with the actual prompt,
the inputs, and the outputs.

**Nothing was moved or deleted** — every file here is a verified copy (MD5-checked).

## Start here

| File | What it is |
|---|---|
| `index.html` | **Open this first.** Every case study with thumbnails, the prompt that produced it, inline video, and click-through to full size. Also the GitHub Pages home page. |
| `00 Best Prompts Library.md` | Every proven prompt as copy-paste text, grouped by technique, with the master exhibition prompt and the fail-condition checklist. |
| `00-cheat-sheets/` | All 8 department cheat sheets and the 10 department pages, deduplicated. |

## What's inside

- **24 case studies** — real jobs with actual prompts, inputs, and outputs
- **115 files** — complete visual documentation
- **Before/after comparisons** — inputs and outputs side by side
- **Video demonstrations** — time-lapse and process videos where available
- **Cheat sheets** — quick reference guides for common patterns

## The case studies

Each numbered folder is one complete example. Files are prefixed so they sort in the order you'd
present them:

```
1 PROMPT …     the actual prompt screenshot
2 BEFORE …     what went in
3 REFERENCE …  sketches and reference images fed alongside
4 AFTER …      what came out
5 VIDEO …      the animated version, where one exists
```

Coverage: sketch→render (01, 02), material interpolation (03), element and furniture swaps (04, 19),
material and colour (05, 08, 17), sketch inpaint (06, 07, 16), multi-reference compositing (09, 10),
clean-up and camera control (11, 15, 18), prompt craft (12), aspect ratios (13), venue placement (14),
stripping a space (20), CAD→lit render (21), the full signage pattern set A–H (22),
colourway variation sets (23), and lit render with animation (24).

## If you're running a workshop

Folder **12** (prompt craft, before/after enhancement) and folder **22** (the A–H pattern set) are the
two strongest teaching assets. Folder **09** shows the four-input multi-reference method — that's the
one people don't believe until they see it.
