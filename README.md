# AI Champions – Best Prompt & Image Examples

A curated collection of 22 real-world case studies demonstrating effective AI prompting and image generation techniques across 10 departments.

## What's Inside

- **22 Case Studies**: Real jobs with actual prompts, inputs, and outputs
- **107 Files**: Complete visual documentation
- **Cheat Sheets**: Quick reference guides for common patterns

## View Online

Open `index.html` in your browser or visit the GitHub Pages site to explore all examples.

## Features

- **Prompt Examples**: Every case includes the exact prompt that was used
- **Before/After Comparisons**: See inputs and outputs side-by-side
- **Video Demonstrations**: Time-lapse and process videos where available
- **Pattern Library**: Reference implementation patterns and techniques

## Quick Start

1. Clone this repository
2. Open `index.html` in your browser
3. Or deploy to GitHub Pages for live hosting

## Structure

```
.
├── index.html                      # Main showcase page
├── 00 Best Prompts Library.md      # Copy-paste prompt reference
├── 00-cheat-sheets/                # Department guides & prompt cheat sheets
└── 01-22 [Case Study Folders]/     # Complete case studies with assets
```
