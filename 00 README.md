## The 22 case studies

Each numbered folder is one complete example. Files are prefixed so they sort in the order you'd
present them:

```
1 PROMPT …     the actual prompt screenshot
2 BEFORE …     what went in
3 REFERENCE …  sketches and reference images fed alongside
4 AFTER …      what came out
5 VIDEO …      the animated version, where one exists
```

Coverage: sketch→render (01, 02), material interpolation (03), element and furniture swaps (04, 19),
material and colour (05, 08, 17), sketch inpaint (06, 07, 16), multi-reference compositing (09, 10),
clean-up and camera control (11, 15, 18), prompt craft (12), aspect ratios (13), venue placement (14),
stripping a space (20), CAD→lit render (21), and the full signage pattern set A–H (22).

## If you're running a workshop

Folder **12** (prompt craft, before/after enhancement) and folder **22** (the A–H pattern set) are the
two strongest teaching assets. Folder **09** shows the four-input multi-reference method — that's the
one people don't believe until they see it.
